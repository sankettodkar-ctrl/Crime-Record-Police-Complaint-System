🚔 Crime Record System

Crime Record & Police Complaint Management System

A digital platform to register, track and manage police complaints.

System Features

📝 Complaint Registration

Citizens can register complaints online.

📄 FIR Registration

Police can record FIR information.

🔍 Complaint Search

Search complaint using Complaint ID.

👮 Admin Dashboard

Police can manage complaints and records.

📊 Crime Statistics

View complaint statistics.

🧾 Print Receipt

Print complaint and FIR receipt.

How the System Works

Simple workflow for citizens and police administration.

1

2

3

Track

Complaint can be searched using ID.

4

Manage
